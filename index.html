三 日常會話情境選擇題（請選出括號中最適合的助詞或語彙）20%【完整 10 題】

含題幹假名、發音與文法解析
1. ( A ) 機場櫃台報到：
パスポート　を　、お願ねがいします。
A. を B. に C. は
解析：動作受詞接賓格助詞「を」，即「パスポートをお願いします」（請給我/請出示護照）。
2. ( B ) 咖啡廳點餐：
コーヒー　を　、ください。
A. が B. を C. で
解析：索取、點餐時名詞後接助詞「を」再接「ください」，意為「請給我咖啡」。
3. ( A ) 詢問洗手間位置：
トイレ　は　、ありますか。
A. は B. を C. が
解析：將詢問主題提出作為話題焦點時使用主題助詞「は」（請問有洗手間嗎？/洗手間在哪裡？）。
4. ( A ) 描述邊走邊聊：
歩あるき　ながら　、話はなします。
A. ながら B. て C. ます
解析：表示同時進行兩項動作接續「動詞ます形去ます + ながら」，「歩きます ➔ 歩き ＋ ながら」表一邊走路一邊說話。
5. ( A ) 飯店詢問票券：
チケット　を　、いただけますか。
A. を B. に C. は
解析：索取物件委託「[名詞] + をいただけますか」，表示高度禮貌地索取票券。
6. ( B ) 試穿看中的鞋子：
履はい　て　、みます。
A. きます B. て C. ながら
解析：表達嘗試體驗使用「動詞て形 + みます」，履きます 的て形為「履いて」，接「みます」即「試穿看看」。
7. ( A ) 形容不小心買太多了：
買かい　すぎます　。
A. すぎます B. ながら C. て
解析：表示行為超過限度使用「動詞ます形去ます + すぎます」，買います ➔ 「買いすぎます / 買いすぎました」（買太多了）。
8. ( B ) 壽司店做點餐決定：
お寿司すし　に　、します。
A. を B. に C. が
解析：在多個菜色或選項中做出個人最後選擇使用「[名詞] + にします」（我決定選壽司）。
9. ( A ) 詢問去日本環球影城的路線：
USJまで　どうやって　、行いきますか。
A. どうやって B. どうして C. どうか
解析：詢問具體交通前往方式、工具與轉乘使用「どうやって行きますか」（怎麼去）。「どうして」為詢問原因理由。
10. ( C ) 在甜點店表達想買的意願：
ケーキを　買い　、たいです。
A. 買います B. 買って C. 買い
解析：表第一人稱想要做某事接「動詞ます形去ます + たいです」，「買います ➔ 買い ＋ たいです」即「想買蛋糕」。

四 日本旅遊生存應答任務（中翻日實戰）20%

點擊右側發音按鈕可反覆跟讀
1. 機上覺得冷：「麻煩請給我毯子（毛布）。」 毛布もうふをお願ねがいします。 (Mōfu o onegai shimasu.)
2. 地鐵詢問轉乘：「請問在哪裡換車（乗り換え）？」 どこで乗のり換かえますか。 (Doko de norikaemasu ka.)
3. 飯店寄放行李：「麻煩（您）了，拜託了。」 よろしくお願ねがいします。 (Yoroshiku onegai shimasu.)
4. 接受協助後致謝：「謝謝。」 ありがとうございます。 (Arigatō gozaimasu.)
5. 在車站補票：「請問精算機在哪裡？」 精算機せいさんきはどこですか。 (Seisanki wa doko desu ka.)

本互動教材支援手機與電腦瀏覽器內建 Web Speech API 日語真人合成引擎（`ja-JP`）。點選每一句對話、句型、練習、常用單字與練習題旁的喇叭圖示，即可發音跟讀！

📱 手機操作要點： iPhone（iOS）若點擊無聲，請確認手機側邊的「靜音開關」已關閉，並將音量調大。
✍️ 第 8 節自我練習題： 點擊選項即可即時批改，並可展開查閱中文文法詳解與題目發音。

加到手機主畫面與離線使用指引

支援飛航模式 / 離線語音發音嗎？

完全支援！ 本系統使用手機內建的作業系統語音庫（iOS 內建 Kyoko/Otoya/Siri，Android 內建 Google TTS）。無網路或開飛航模式時依然能正常發音！

iPhone / iPad (Safari) 安裝方式：
  1. 請使用 Safari 瀏覽器開啟本教材網頁。
  2. 點擊瀏覽器底部的 分享按鈕（中間向上箭頭方塊 ）。
  3. 往下滑動選單，點選 「加入主畫面」（Add to Home Screen）。
  4. 確認名稱後按右上角「新增」，手機桌面即會產生專屬 App 圖示，點開即可全螢幕無網址列沉浸式學習！
Android (Chrome) 安裝方式：
  1. 點擊上方或畫面上的 「安裝 App」 按鈕；或點右上角 「⋮」 選單。
  2. 選擇 「安裝應用程式」 或 「加到主螢幕」。
  3. 安裝完成後即可從手機主畫面獨立以 App 形式開啟。
若離線點擊無聲音時的設定確認：
  • iPhone：請確認手機側邊的「靜音開關」已切換為開啟聲音。
  • Android：至手機「設定 → 系統 → 語言與輸入 → 文字轉語音輸出」，確認 Google 語音已下載「日文語音資料包（約 15MB）」。
