手機發音與操作提示

本互動教材支援手機與電腦瀏覽器內建 Web Speech API 日語真人合成引擎（`ja-JP`）。點選每一句對話、句型、練習與常用單字旁的喇叭圖示，即可發音跟讀！

📱 手機操作要點： iPhone（iOS）若點擊無聲，請確認手機側邊的「靜音開關」已關閉，並將音量調大。
⚡ 語速調整： 於上方隨時切換 0.75x（慢速精聽）或 0.9x（標準學習）。
